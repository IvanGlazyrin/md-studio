| Ключ | Тип | Что делает | По умолчанию |
| --- | --- | --- | --- |
| `title` | string | Заголовок страницы | имя файла |
| `nav_title` | string | Подпись в боковом меню | `title` |
| `nav_order` | number | Порядок в меню | `Infinity` |

Значения, которых нет в схеме, сохраняются: студия не переписывает ваш
фронтматтер целиком, а только те ключи, которые сама понимает.
