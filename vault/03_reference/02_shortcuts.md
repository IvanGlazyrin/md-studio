| Действие | Как |
| --- | --- |
| Поиск по документации | `Ctrl` / `Cmd` + `K` |
| Открыть меню на узком экране | кнопка слева в шапке |
| Перейти к якорю | клик по заголовку в оглавлении справа |
| Добавить TODO на строку | клик по номеру строки слева от текста |
| Удалить заметку | корзина в поповере |

## Панели

- **Слева** — дерево разделов, собранное из папок хранилища.
- **Справа** — оглавление текущей страницы.
- **Сверху** — имя подключённой папки и поиск.
