Студия читает одну папку. По умолчанию — `vault/` рядом с `package.json`.
Свою папку указывают через переменную окружения `DOCS_DIR`.

```bash
DOCS_DIR=/home/user/notes npm run dev
```

В PowerShell:

```powershell
$env:DOCS_DIR = "C:\Users\me\notes"
npm run dev
```

Путь считается от рабочей директории, если он не абсолютный.

## Как выглядит папка

```
my-notes/
  00_index.md          # индекс хранилища
  01_intro/
    01_welcome.md
  02_api/
    01_endpoints.md
    reference.md
```

- Папка верхнего уровня — раздел бокового меню, её имя превращается в заголовок.
- Вложенная папка — группа внутри раздела.
- Файл `00_index.md` в папке — её индекс по адресу `/docs/<папка>`.
- Папки `assets/` и `.obsidian/` в меню не попадают.

## Где хранятся TODO

Заметки на строках пишутся в `data/doc-todos.json` рядом с проектом. Путь
переопределяется переменной `DOC_TODOS_FILE` — удобно, когда документы лежат
в одной папке, а заметки должны попадать в репозиторий:

```bash
DOCS_DIR=../notes DOC_TODOS_FILE=../notes/.todos.json npm run dev
```

> [!warning] Заметки пишутся на диск
> API создаёт и удаляет записи в JSON-файле. Если папку документации нельзя
> менять, оставьте `DOC_TODOS_FILE` в своём проекте.
